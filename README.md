# Простой HTTP-сервер на 1С Элемент.Скрипт

> **Примечание:** данный проект является учебным, имеет ограниченный
> функционал и не предназначен для продакшен-разработки.

Проект представляет собой простой HTTP-сервер на **1С Элемент.Скрипт**.

В `Скрипт.bsl` содержится пример: - создания сервера, роутера и
менеджера соединений; - регистрации пути в роутере; - написания
функций-обработчиков; - запуска сервера; - прослушивания TCP-соединений.

## Описание содержимого `ВебСервер.sbsl`

### Основные структуры

## Структура `Запрос`

### Поля

  -----------------------------------------------------------------------
  Поле                                Описание
  ----------------------------------- -----------------------------------
  `АдресКлиента`                      IP-адрес клиента, со стороны
                                      которого поступил запрос

  `ТипЗапроса`                        HTTP-метод, выбранный для запроса

  `ПутьЗапроса`                       Строка пути запроса, например
                                      `/api/users`

  `ВерсияHTTP`                        Версия протокола HTTP, которая
                                      использовалась для отправки запроса

  `Тело`                              Тело отправленного запроса

  `Заголовки`                         Заголовки ответа, соответствующие
                                      типу `Соответствие<Строка, Строка>`
  -----------------------------------------------------------------------

### Глобальные методы

#### `ВывестиПредставление`

Выводит информацию о запросе в консоль:

-   `ТипЗапроса + ПутьЗапроса`;
-   заголовки в формате `НазваниеЗаголовка: ЗначениеЗаголовка`;
-   `ТелоЗапроса`.

------------------------------------------------------------------------

## Структура `Ответ`

### Поля

  ---------------------------------------------------------------------------
  Поле                                Описание
  ----------------------------------- ---------------------------------------
  `ВерсияHTTP`                        Версия протокола HTTP, которая
                                      использовалась для отправки запроса

  `Статус`                            Статус ответа

  `Заголовки`                         Заголовки ответа, соответствующие типу
                                      `Соответствие<Строка, Строка\|Число>`

  `Тело`                              Тело отправленного ответа
  ---------------------------------------------------------------------------

### Глобальные методы

#### `СоздатьОтвет`

Статический метод `СоздатьОтвет` создаёт экземпляр структуры `Ответ`.

Дополнительно в заголовки ответа добавляются:

-   `Content-Type` --- по умолчанию `application/json`;
-   `Content-Length`.

------------------------------------------------------------------------

## Структура `Путь`

### Поля

  Поле           Описание
  -------------- -------------------------------------
  `HTTPМетод`    HTTP-метод, с которым работает путь
  `СтрокаПути`   Строка пути

Глобальные методы отсутствуют.

------------------------------------------------------------------------

## Структура `Сервер`

### Поля

  Поле      Описание
  --------- ----------------------------------------
  `Адрес`   IP-адрес, на котором запустится сервер
  `Порт`    Порт, на котором запустится сервер

### Глобальные методы

#### `ЗапуститьСервер`

Запускает блокирующий TCP-сервер на указанном адресе и порте.

#### `НовыйСервер`

Статический метод `НовыйСервер` создаёт экземпляр структуры `Сервер`.

------------------------------------------------------------------------

## Структура `МенеджерСоединений`

### Поля

  Поле       Описание
  ---------- ------------------------------
  `Роутер`   Экземпляр структуры `Роутер`

### Глобальные методы

#### `СлушатьСоединения`

Прослушивает входящие TCP-соединения, читает данные из соединения и
создаёт запрос с помощью локального статического метода структуры
`Запрос` --- `СоздатьЗапрос`, который, в свою очередь, преобразует
строку в структуру `Запрос`.

После этого создаётся `ПотокЗаписи`, а сформированный `Запрос`
передаётся в `Роутер`.

#### `НовыйМенеджерСоединений`

Статический метод `НовыйМенеджерСоединений` создаёт экземпляр структуры
`МенеджерСоединений`.

------------------------------------------------------------------------

## Структура `Роутер`

### Поля

`КартаПутей` имеет тип:

``` text
Соответствие<Путь, (Запрос) -> Ответ>
```

Ключ --- `Путь`, значение --- лямбда-выражение для подстановки
обработчиков, сигнатура которых должна соответствовать сигнатуре
лямбда-выражения.

### Глобальные методы

#### `ЗарегистрироватьПуть`

Метод принимает `Путь` в виде строки:

``` text
ТипЗапроса СтрокаПути
```

Например:

``` text
GET /api/users
```

Также метод принимает обработчик, соответствующий сигнатуре
лямбда-выражения:

``` text
(Запрос) -> Ответ
```

где `Запрос` и `Ответ` --- структуры.

Метод преобразует строку в экземпляр структуры `Путь` и регистрирует
путь с обработчиком в `КартаПутей`.
