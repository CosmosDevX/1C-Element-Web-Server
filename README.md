# Простой веб-фреймворк на 1С Элемент.Скрипт

> Данный проект является учебным и не предназначен для продакшен-разработки и имеет ограниченный функционал.

Проект представляет собой прототип веб-фреймворка на 1С Элемент.Скрипт.

В `Скрипт.bsl` содержится пример использования на примере:

- создания сервера, роутера, менеджера соединений;
- регистрации пути в роутере;
- написания функций-обработчиков;
- запуска сервера и прослушивания TCP соединений.

### Основные структуры модуля ВебСервер(#требуется ВебФреймворк)

#### Структура `Запрос`

**Поля:**

| Поле | Описание |
| --- | --- |
| `АдресКлиента` | IP адрес клиента, со стороны которого поступил запрос |
| `ТипЗапроса` | HTTP метод, выбранный для запроса |
| `ПутьЗапроса` | Строка пути запроса, например `/api/users` |
| `ВерсияHTTP` | Версия протокола HTTP, которая использовалась для отправки запроса |
| `Тело` | Тело отправленного запроса |
| `Заголовки` | Заголовки запроса, соответствующие типу `Соответствие<Строка, Строка>` |
| `ПараметрыЗапроса` | параметры запроса, соответствующие типу `Соответствие<Строка, Строка>` |
| `ПараметрыПути` | параметры пути, соответствующие типу `Соответствие<Строка, Строка>` |

**Глобальные методы:**

Метод `ВывестиПредставление` выводит информацию о запросе в консоль:

- `ТипЗапроса` + `ПутьЗапроса`;
- `Заголовоки` в формате `НазваниеЗаголовка: ЗначениеЗаголовка`;
- `ТелоЗапроса`;
- `ПараметрыПути` в формате `НазваниеПараметраПути: ЗначениеПараметраПути`, при отсутствии выведется соответствующее сообщение; 
- `ПараметрыЗапроса` в формате `НазваниеПараметраЗапроса: ЗначениеПараметраЗапроса`, при отсутствии выведется соответствующее сообщение; 

#### Структура `Ответ`

**Поля:**

| Поле | Описание |
| --- | --- |
| `ВерсияHTTP` | Версия протокола HTTP, которая использовалась для отправки запроса |
| `Статус` | Статус ответа |
| `Заголовки` | Заголовки ответа, соответствующие типу `Соответствие<Строка, Строка\|Число>` |
| `Тело` | Тело отправленного ответа |

**Глобальные методы:**

Статический метод `СоздатьОтвет` создаёт экземпляр структуры `Ответ`.

Дополнительно в заголовки ответа добавляются:

- `Content-Type` — по умолчанию `application/json`;
- `Content-Length`.

#### Структура `Путь`

**Поля:**

| Поле | Описание |
| --- | --- |
| `HTTPМетод` | HTTP метод, с которым работает путь |
| `СтрокаПути` | Строка пути |

Нет глобальных методов.

#### Структура `Сервер`

**Поля:**

| Поле | Описание |
| --- | --- |
| `Адрес` | IP адрес, на котором запустится сервер |
| `Порт` | Порт, на котором запустится сервер |

**Глобальные методы:**

- Метод `Слушать` выполняет обработку входящих TCP соединений, извлечение HTTP запроса и его перенаправление в Роутер. После успешного перенаправления запроса в Роутер отправляет ответ клиенту.
- Статический метод `НовыйСервер` создаёт экземпляр структуры `Сервер`.

#### Структура `Роутер`

**Поля:**

`КартаПутей` (тип `Соответствие<Путь, (Запрос) -> Ответ>`).

Ключ — `Путь`, значение — лямбда-выражение для подстановки обработчиков, сигнатура которых должна соответствовать сигнатуре лямбда-выражения.

**Глобальные методы:**

Метод `ЗарегистрироватьПуть` принимает `Путь` в виде строки `ТипЗапроса СтрокаПути`, например `GET /api/users`, и метод, соответствующий сигнатуре лямбда-выражения `(Запрос) -> Ответ`.

Метод парсит строку в экземпляр структуры `Путь` и регистрирует путь с обработчиком в `КартаПутей`.

Статический метод `НовыйРоутер` создаёт экземпляр структуры `Роутер`.

### Основные структуры модуля Валидация(#требуется ВебФреймворк)

#### Структура `ПравилоВалидации`

**Поля:**

| Поле | Описание |
| --- | --- |
| `СтрокаПараметров` | строка с параметрами в формате "Правило = Значение;". Например: "минимум = 15; максимум = 40" |

#### Структура `Валидатор`

**Поля:**
Имеет только внутреннее поле, хранящее правила и обработчики для правил

**Глобальные методы:**

Метод `Валидировать` выполняет валидацию свойств экземпляра структуры по заданным правилам.

Статический метод `НовыйВалидатор` создаёт экземпляр структуры `Валидатор`.
