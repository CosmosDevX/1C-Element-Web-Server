# Простой HTTP сервер на 1С Элемент.Скрипт

> Данный проект является учебным и не предназначен для продакшен-разработки и имеет ограниченный функционал.

Проект представляет собой простой HTTP сервер на 1С Элемент.Скрипт.

В `Скрипт.bsl` содержится пример использования на примере:

- создания сервера, роутера, менеджера соединений;
- регистрации пути в роутере;
- написания функций-обработчиков;
- запуска сервера и прослушивания TCP соединений.

## Описание содержания `ВебСервер.sbsl`

### Основные структуры

#### Структура `Запрос`

**Поля:**

| Поле | Описание |
| --- | --- |
| `АдресКлиента` | IP адрес клиента, со стороны которого поступил запрос |
| `ТипЗапроса` | HTTP метод, выбранный для запроса |
| `ПутьЗапроса` | Строка пути запроса, например `/api/users` |
| `ВерсияHTTP` | Версия протокола HTTP, которая использовалась для отправки запроса |
| `Тело` | Тело отправленного запроса |
| `Заголовки` | Заголовки ответа, соответствующие типу `Соответствие<Строка, Строка>` |

**Глобальные методы:**

Метод `ВывестиПредставление` выводит информацию о запросе в консоль:

- `ТипЗапроса` + `ПутьЗапроса`;
- заголовки в формате `НазваниеЗаголовка: ЗначениеЗаголовка`;
- `ТелоЗапроса`.

#### Структура `Ответ`

**Поля:**

| Поле | Описание |
| --- | --- |
| `ВерсияHTTP` | Версия протокола HTTP, которая использовалась для отправки запроса |
| `Статус` | Статус ответа |
| `Заголовки` | Заголовки ответа, соответствующие типу `Соответствие<Строка, Строка\|Число>` |
| `Тело` | Тело отправленного ответа |

**Глобальные методы:**

Статический метод `СоздатьОтвет` создаёт экземпляр структуры `Ответ`.

Дополнительно в заголовки ответа добавляются:

- `Content-Type` — по умолчанию `application/json`;
- `Content-Length`.

#### Структура `Путь`

**Поля:**

| Поле | Описание |
| --- | --- |
| `HTTPМетод` | HTTP метод, с которым работает путь |
| `СтрокаПути` | Строка пути |

Нет глобальных методов.

#### Структура `Сервер`

**Поля:**

| Поле | Описание |
| --- | --- |
| `Адрес` | IP адрес, на котором запустится сервер |
| `Порт` | Порт, на котором запустится сервер |

**Глобальные методы:**

- Метод `ЗапуститьСервер` запускает блокирующий TCP сервер на указанном адресе и порте.
- Статический метод `НовыйСервер` создаёт экземпляр структуры `Сервер`.

#### Структура `МенеджерСоединений`

**Поля:**

| Поле | Описание |
| --- | --- |
| `Роутер` | Экземпляр структуры `Роутер` |

**Глобальные методы:**

Метод `СлушатьСоединения` прослушивает входящие TCP соединения, читает данные из соединения, создаёт запрос с помощью локального статического метода структуры `Запрос` — `СоздатьЗапрос`, который, в свою очередь, парсит строку в структуру `Запрос`. После чего создаёт `ПотокЗаписи`, сформированный `Запрос` передаётся в `Роутер`.

Статический метод `НовыйМенеджерСоединений` создаёт экземпляр структуры `МенеджерСоединений`.

#### Структура `Роутер`

**Поля:**

`КартаПутей` (тип `Соответствие<Путь, (Запрос) -> Ответ>`).

Ключ — `Путь`, значение — лямбда-выражение для подстановки обработчиков, сигнатура которых должна соответствовать сигнатуре лямбда-выражения.

**Глобальные методы:**

Метод `ЗарегистрироватьПуть` принимает `Путь` в виде строки `ТипЗапроса СтрокаПути`, например `GET /api/users`, и метод, соответствующий сигнатуре лямбда-выражения `(Запрос) -> Ответ`, где `Запрос` и `Ответ` — структуры.

Метод парсит строку в экземпляр структуры `Путь` и регистрирует путь с обработчиком в `КартаПутей`.
