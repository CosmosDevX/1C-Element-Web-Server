# Простой HTTP-сервер на 1С Элемент.Скрипт

> [!NOTE]
> Учебный проект с ограниченным функционалом. Не предназначен для использования в продакшене.

Проект демонстрирует работу простого HTTP-сервера на **1С Элемент.Скрипт**.

В файле [`Скрипт.sbsl`](Скрипт.sbsl) показано, как:

- создать сервер, роутер и менеджер соединений;
- зарегистрировать путь в роутере;
- написать обработчики запросов;
- запустить сервер и прослушивать TCP-соединения.

## Содержимое `ВебСервер.sbsl`

### Структура `Запрос`

| Поле | Описание |
| --- | --- |
| `АдресКлиента` | IP-адрес клиента, от которого поступил запрос. |
| `ТипЗапроса` | HTTP-метод запроса. |
| `ПутьЗапроса` | Путь запроса, например `/api/users`. |
| `ВерсияHTTP` | Версия HTTP, использованная для отправки запроса. |
| `Тело` | Тело запроса. |
| `Заголовки` | Заголовки запроса типа `Соответствие<Строка, Строка>`. |

**`ВывестиПредставление`** выводит в консоль:

- HTTP-метод и путь запроса;
- заголовки в формате `НазваниеЗаголовка: ЗначениеЗаголовка`;
- тело запроса.

### Структура `Ответ`

| Поле | Описание |
| --- | --- |
| `ВерсияHTTP` | Версия HTTP, использованная для отправки ответа. |
| `Статус` | Статус ответа. |
| `Заголовки` | Заголовки ответа типа `Соответствие<Строка, Строка\|Число>`. |
| `Тело` | Тело ответа. |

**`СоздатьОтвет`** — статический метод, создающий экземпляр структуры `Ответ`. В заголовки добавляются `Content-Type` (по умолчанию `application/json`) и `Content-Length`.

### Структура `Путь`

| Поле | Описание |
| --- | --- |
| `HTTPМетод` | HTTP-метод, с которым работает путь. |
| `СтрокаПути` | Строка пути. |

Глобальных методов нет.

### Структура `Сервер`

| Поле | Описание |
| --- | --- |
| `Адрес` | IP-адрес, на котором запускается сервер. |
| `Порт` | Порт, на котором запускается сервер. |

- **`ЗапуститьСервер`** запускает блокирующий TCP-сервер на указанном адресе и порте.
- **`НовыйСервер`** — статический метод, создающий экземпляр структуры `Сервер`.

### Структура `МенеджерСоединений`

| Поле | Описание |
| --- | --- |
| `Роутер` | Экземпляр структуры `Роутер`. |

**`СлушатьСоединения`** принимает входящие TCP-соединения и читает данные. Локальный статический метод `Запрос.СоздатьЗапрос` преобразует полученную строку в структуру `Запрос`. Затем создаётся `ПотокЗаписи`, а запрос передаётся в `Роутер`.

**`НовыйМенеджерСоединений`** — статический метод, создающий экземпляр структуры `МенеджерСоединений`.

### Структура `Роутер`

Поле `КартаПутей` имеет тип:

```text
Соответствие<Путь, (Запрос) -> Ответ>
```

Ключ карты — структура `Путь`, значение — обработчик с сигнатурой `(Запрос) -> Ответ`.

**`ЗарегистрироватьПуть`** принимает строку в формате `ТипЗапроса СтрокаПути`, например:

```text
GET /api/users
```

Второй аргумент — обработчик с сигнатурой `(Запрос) -> Ответ`. Метод преобразует строку в структуру `Путь` и регистрирует её вместе с обработчиком в `КартаПутей`.
